# Lumina · AI 动态学习工作台

对话驱动的自适应导师：讲解、可交互教材、练习判题、可追溯的学习证据，全部跑在一个本地 Next.js + SQLite 应用里。

```
提问 → 真实模型流式回答 → 工具生成练习/图表/模拟器 → 作答服务端判题
     → 写入证据 → BKT 更新掌握度 → 跨会话恢复 → 复习建议
```

## 两种学习模式

- **无限学习**：直接开始 AI 对话，不需要计划。可以连续追问、换讲法、要练习；练习只用于即时反馈，不写入正式学习档案，也不生成课程完成率。只有学生明确要求「整理成计划」时，才生成一份待确认的计划草稿。
- **目标学习**：先设定目标，AI 生成「计划 → 课程 → 知识点」草稿；用户确认或修改后才开始正式学习。每个知识点只归属一门课程，课程与计划进度都从同一份知识点状态计算。

目标学习的进度口径：学习进度按知识点状态加权（已掌握 100% / 学习中 40% / 待复习 20% / 待学习 0%），但只有课程内知识点全部「已掌握」才算课程完成；未配置知识点的课程会明确标出，且不计入完成率。

## 快速开始

**Windows 最省事**：双击项目根目录的 `start.bat`，它会自动检查依赖、构建、启动并打开浏览器。

命令行方式：

```bash
npm install
cp .env.example .env.local     # 可选：也可以启动后在「设置」页填
npm run dev                    # http://localhost:3210
```

首次打开会提示「模型服务未配置」——这是**刻意**的：没有真实模型时，应用不会用固定话术假装教学。

到「设置 → 模型服务」添加模型（内置 DeepSeek / 通义 / Kimi / 智谱 / 火山方舟 / Ollama / OpenAI / Anthropic 预设），点「保存并测试」会真的发一次请求。

**支持多个模型并存**：

- 可以保存多套配置（不同厂商、不同价位、本地 + 云端混用），其中一套为「默认」
- 对话页左下角可随时切换，切换只影响当前会话，并会被记住（刷新后仍用它）
- 每条回答下方标注实际使用的模型，方便对比同一个问题不同模型怎么讲
- 删除某套配置不会删学习记录；正在用它的会话自动回到默认模型

```bash
# 生产
npm run build && npm run start

# 测试
npm test                       # 单元 + 集成测试（判题 / BKT / 调度 / 聚合重算）
npm run demo:llm               # 启动本地测试替身模型（不是 AI，只用于验证链路）
npm run demo:web               # 启动本地测试替身搜索服务（可切换超时/401/429/空结果）
node tests/smoke.mjs           # 端到端：流式 → 组件 → 判题 → 证据 → 幂等 → 删除语义
DEMO_SESSION=<会话id> node tests/ui-check.mjs   # 真实浏览器交互验证（需本机 Edge/Chrome）
```

## 界面

- 首页是学习工作台：今天该学什么 / 学习时间 / 目标进度 / 需要再练，四块都是真实数据，空状态不造假任务
- 「新对话」是独立页（/new，侧栏顶部那一行进它）：一个输入框，直接问或切到「定目标」排计划草稿；侧栏还有搜索放大镜 + 对话列表
- 导航只有四项：学习 / 计划 / 复习 / 档案；档案里分「知识点 / 对话 / 材料」三个 tab，共用搜索与筛选
- 搜索是全局搜索：一次搜对话 / 计划 / 知识点 / 材料，结果分组展示，键盘 ↑↓ 选择、Enter 打开、Esc 关闭
- 侧栏对话按「置顶 / 计划 / 最近」三组排；计划可以展开看关联对话；悬停会话条或计划条，右边出现三个点和图钉（菜单贴在侧栏右缘、一半露在栏外）
  - 会话：重命名 / 置顶 / 移至计划 / 删除；计划：重命名 / 置顶 / 计划详细 / 删除（删计划会带走课程和知识点，弹窗里写明）
- 侧栏可折叠成图标栏（状态记在本机）；折叠后没有单独的折叠按钮，软件图标本身就是展开按钮，鼠标悬停不会自己弹开
- 重命名、移至计划、删除都在页面中间弹窗里完成（从侧栏点开的也一样）
- 对话页右上角三个点收着「生成小结 / 学习档案 / 删除会话」，菜单窄、往右挪，不挡正文
- 只在会误解或不可逆的地方写解释（模型未配置、删除后果、联网边界、材料格式），其余状态用徽标和一句话空态表达
## 已实现

**学习工作台**

- 首页就是工作台：内容区宽屏 1024、窄屏单列；今天该学什么（整行）在上，学习时间（占两列）与目标进度并排，需要再练收尾；空态只占一行，不撑高卡片
- 「新对话」独立成 /new：一个输入框 + 三个例子，发出去才建会话，空会话不会污染侧栏
- 学习时长是真实计时：只在对话 / 复习 / 课程页且页面可见时按秒累计，**攒满 30 秒才入库一次**（不满的零头跨页累计）；单次限幅 30–120 秒，乱写的数字直接丢
- 只存「本地日期 + 秒数」，不记录学习内容；日视图最近 14 天、周视图本周七天（星期一…星期日）、月视图今年 1–12 月，外加累计 / 学习天数 / 连续天数；**不足一分钟不画柱子**，没学过的日子图上就是空的
- 时长聚合有单测覆盖：跨零点、周一起来算、断签、空数据都不造假

**教学闭环**
- 真实模型流式回答（SSE），逐字上屏
- 模型通过 9 个白名单工具输出结构化内容：登记知识点、出练习、多题小测、画图、对比表、步骤演示、参数模拟器、生成计划草稿、学习小结
- 服务端 zod 校验；校验失败降级为文字，不伪造组件
- 模型未配置 / 超时 / 限流 / 输出格式错误 / 客户端中断，全部有明确提示且保留已生成内容
- 讲解风格是可保存的多张自定义卡片：点「添加风格」写一句「你希望我怎么讲」（≤500 字）+ 篇幅 1–5 + 举例/检验开关；同一时间只有一个生效，可以按场景切换（如「日常」/「考前」）；不设置时不额外注入任何提示词

**练习与判题**
- 8 种题型：单选、多选、填空、判断、排序、计算、分步骤、开放题
- 答案与评分规则只存服务端，提交前绝不下发；提交后才返回标准答案
- 非唯一答案的开放题交给模型按评分维度评阅；模型不可用时标记「未评阅」，**不计入**掌握度
- 幂等键在同一次作答内按「练习 + 作答内容」稳定生成：连点 / 网络重试只计一次证据；「再做一次」会换新键，重做才算新证据
- 「看过解析 / 用过提示」由服务端留痕并覆盖客户端自报，无法用 `viewedSolution:false` 绕过
- 空提交不算答错：没填/没选时返回「未作答」，不写证据，也不会被兜底判成某一个选项
- 判题归一：数值题默认容差 0.1%（大数设绝对上限），填空题认 `1000.00 = 1000`、`50% = 50`、全角数字与千分位，纯文本答案仍按文本规则
- 题目二次校验（出题质量门）：答案键、选项唯一性、题干自洽、泄题/歧义；通过才计入证据，歧义题会标注且不计入，校验失败的题降级为文字练习
- 多题小测：一次 2–5 道确定性题，可覆盖同一课程里的多个知识点（每题可指定知识点），统一提交；显示「第 n 题 / 共 N 题」、答对 x/n、平均得分和逐题反馈
- 提示、查看解析（会标记为「非独立完成」）、跳过、再做一次
- 「再做一次」只清题目级标记，不恢复独立性：答案一旦下发过（提交后必然下发），重做只作练习记录，不再计入独立正确与掌握度

**诊断与行动**
- 错因结构化：判题器推断「概念混淆 / 计算失误 / 审题遗漏 / 表述不全」，注入下一轮讲法（不参与掌握度）
- 结构化复习：会话绑定知识点与复习条目，先测后讲；独立答对自动收尾，未作答保留条目；档案「练一练」也走结构化复习
- 单条证据作废：误判/坏题可标记「这条不算」，软作废并重放剩余证据
- 今日计划：学习页给一个 10 分钟的确定动作（到期复习 > 最薄弱 > 继续上次），没有就空态；复习建议可直接点击开始
- 题目反馈：太简单 / 太难 / 有问题；「有问题」作废该题证据，「换一题」换题型重新生成
- 目标学习结构：计划 → 课程（plan_items）→ 知识点（concepts.course_id）；一个知识点只归属一门课程，没有归属的知识点在档案里标为「待整理」
- 计划草稿必须由用户确认：AI 只生成待确认结构，确认前不会产生学习进度；计划页可增删改课程、知识点、调整顺序、暂停或跳过课程
- 删除计划、删除计划里的某门课程、或在课程里移除某个知识点，都会连带删除该知识点与它上面的作答/掌握度证据（确认框写明数量，不可撤销）；对话与材料保留，只解除关联；仍被其它计划/课程使用的知识点只解除归属
- 课程与计划进度统一按知识点状态计算：学习进度加权展示，课程完成严格要求该课程全部知识点已掌握；未配置知识点的课程单独提示且不计入完成率

**来源可溯源**
- 回答可标注依据：本地材料用 `[[m1]]`、网络来源用 `[[w1]]`，正文里渲染成可点角标
- 服务端只认本轮真实注入的来源 id：模型伪造的引用会被剥离并明确提示，不会产生死链
- 来源卡片显示材料名/片段（有页码时显示页码）或域名/发布日期/摘要，可点回原文（材料定位到具体切片）
- 没有来源时标注「模型知识」，不硬凑引用
- 联网检索默认关闭，且**不绑定服务商**：填一个返回 JSON 的搜索接口（地址 + GET/POST + 认证请求头/Key，请求体模板、结果路径与字段映射在「高级」里）就能用；保存时可一键真测；手动开启后先查证再作答，失败会明说「未能联网核实」

**学习证据与掌握度**
- BKT 贝叶斯知识追踪（移植自 OpenTutor，MIT，见致谢）：个人化 guess/slip 参数，按题型调整
- 提示依赖、独立完成、题目多样性都进入判定；同一道题重复刷不会堆出掌握度
- 状态五档内部保留（尚未接触 / 正在学习 / 需要巩固 / 有初步掌握证据 / 暂时掌握），普通界面统一显示四态：待学习 / 学习中 / 待复习 / 已掌握
- 档案按计划与课程分组；p 值、证据次数等内部指标放进知识点详情，不占据列表主视觉
- 档案可维护：删除单个知识点、一键清理「从未归属课程且零证据」的空壳、合并重复（同名一键 / 近似概念手动）、人工更正状态（均留审计）
- 已讲解但未测的知识点显示「学习中」，不会被当成「尚未接触」或空壳清掉；未归属课程的知识点单独列为待整理
- 概念按 canonical 名称全局去重：同一概念换主题出现时复用原档案；已属于其他课程的知识点不会为了新计划强行复制，计划草稿会明确提示冲突
- 每次状态变化写审计（原因、前后 p 值），可查看、可人工更正
- 「已掌握」会回收：复习到期或 90 天没有任何作答，界面退回「待复习」，课程完成度随之下落
- 独立性由服务端从历史推导（答案一旦下发过就不算独立完成），刷新页面也拿不到未判定题目的答案
- FSRS 启发式复习调度，复习队列按真实证据生成（连错、依赖提示、单一题型、到期）

**会话与工作区**
- 会话自动保存、断点恢复、标题可改、模式区分（无限学习 / 目标学习 / 复习）；无限学习的历史不会混进正式计划
- 复杂内容可展开到独立工作区，参数与作答草稿自动保存，刷新后恢复
- 流式回答按 50ms 合批渲染，长回答不再逐 token 卡顿；失败或中断可原地「重试这次回答」（复用同一条提问，不会多出一条）
- 设置页「用量」看真实 token：今日/本月/累计、按模型拆分、平均延迟与失败次数（不维护价格表，也不替你估成本）
- 工作区提问使用会话绑定的模型，一次性生成（非流式）；引用会校验并落库来源，也写入用量日志
- 删除会话默认**保留**长期学习证据；可显式勾选连带删除

**材料**
- txt/md/csv/json/html/pdf/docx 解析，段落级切片，按关键词检索注入上下文；HTML 会先去掉脚本与样式
- 材料内容按「不可信数据」注入提示词，其中的指令不会被执行
- 解析失败如实报告；扫描件 PDF / .doc / .pptx 明确标记不支持，不伪造内容

## 已知限制

- 单用户本地模式，**默认只监听 `127.0.0.1`**；需要局域网访问用 `npm run start:lan`，
  并建议同时设置 `APP_ACCESS_TOKEN`（已内置 Cookie 令牌校验）。
- 没有 OCR：扫描版 PDF 无法提取文本。
- 会话默认加载**最新 200 条**消息（接口支持 `?before=<seq>` 向前翻页，界面暂无「加载更早」入口）。
- 「已掌握」会回收：到期未复习或 90 天没有任何作答证据，界面退回「待复习」，课程完成度随之回落。
- 可以删除知识点（连带其证据与掌握度记录）、或一键清理「零证据的空壳知识点」；单条证据可标记「这条不算」软作废，保留审计。
- 复习只做站内队列，不做浏览器推送（需要授权，未实现）。
- 开放题评阅质量取决于所用模型。
- 题目二次校验与主模型共用同一套配置：校验模型不可用时，题目会标为「未校验」且不计入掌握度。
- 关键词检索而非向量检索：先在 SQL 里 LIKE 粗筛再排序，材料很多时召回仍有限。
