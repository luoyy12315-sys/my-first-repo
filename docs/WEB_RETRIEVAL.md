## Phase 1

**引用协议**：正文用 `[[m1]]`（材料）/ `[[w1]]`（网络）标注依据。

- `src/lib/ai/citations.ts`：解析、校验、剥离、统计；`stripPartialCitation` 处理流式半截 token；`renderCitationsForExport` 供复制/导出转成 `[1]` + 来源列表。
- **只认本轮注入的 id**：模型伪造的 `[[w9]]` 会被剥离并提示"模型引用了不存在的来源，已移除"；全部无效时不自动补引用（补引用等于伪造）。
- 落库：`message_sources` 表 + `saveMessageSources()`；`listMessages` 一次性批量带出来源。
- 注入：`buildTeachingMessages` 增加材料块（`[M1]《材料名》第 N 页`）与引用规则块。
- UI：正文里的 token 渲染成角标（`.citation-chip`），点一下跳到来源卡片；消息下方渲染来源卡片（材料名/页码/片段/打开材料、网络域名/发布日期/摘要/打开原页、可能已过期标记、来源反馈菜单）；没有来源时显示灰色"模型知识"。
- 点回原文：来源卡片 → `/materials?chunk=<chunkId>` → 材料页显示"引用来源"面板并高亮对应材料行。

**顺带修的真问题**：材料切片检索之前把整句当 LIKE 条件，`根据我的材料，讲讲机会成本是什么` 一个词都命中不了，材料引用根本触发不了。现在会去掉虚词并对长片段补 2 字窗口（`extractQueryTerms`）。

## Phase 2

**前置检索**（不做工具循环）：`/api/chat` 在 `streamChat` 之前完成检索，来源注入 prompt。

- `src/lib/web/`：`config.ts`（配置）、`provider.ts`（SearXNG / Tavily / Brave）、`fetch.ts`（SSRF 防护 + 正文抽取）、`score.ts`（规范化去重 + 可解释评分）、`cache.ts`（TTL 缓存 + 日志 + 预算）、`gate.ts`（门控 / 查询规划 / PII 脱敏）、`retrieve.ts`（编排）。
- **门控只有手动模式**：`webMode=off|manual`。自动意图识别留到 Phase 3——现在做等于拿真实用户当评测集。
- **SSE**：新增 `search_status`（searching/done/failed）与 `sources` 事件；`done` 事件附带最终使用的来源。
- **失败诚实**：未配置 / 超时 / 401 / 429 / 无结果 / 质量不足 / 预算用尽，各有明确文案，且**不产生任何来源卡片或假引用**。
- **缓存**：key = `sha256(provider|query|max|freshness|domains)`；新闻类 query 强制 1 天 TTL；过期且刷新失败时用旧缓存并标 `stale`。
- **预算**：每会话真实 provider 调用上限（默认 6），缓存命中不计数。
- **SSRF**：只允许 http/https；DNS 解析后阻断私网/回环/链路本地/保留地址；重定向逐跳重校验（≤3 跳）；响应体 ≤2MB；只接受 text/html|text/plain。自建服务地址（127.0.0.1）由用户显式配置开关允许。
- **判题隔离**：`/api/attempts`、提示、解析、出题工具都不触发检索（代码路径上根本不走检索模块），并有计数断言。
- **设置页**：联网检索区块（总开关、provider、Base URL、Key、最大来源数、超时、缓存天数、每会话次数、域名黑白名单、默认模式、允许自建地址、测试搜索、7 天统计）。
- **对话开关**：输入框左侧地球图标，`联网：关闭 / 手动`，状态存 localStorage（不写会话）。
- **来源反馈**：每条来源右上角「···」→ 不相关 / 已过期 / 打不开 / 内容有误 → `POST /api/source-feedback`。

端到端里的联网用例（用 `tests/mock-web-server.mjs`，端口 4319，可切换 normal/empty/timeout/401/429 并计数）：

1. `webMode=off` → provider 计数 **0**
2. `webMode=manual` → 有 `search_status`/`sources` 事件、回答含 `[[w1]]`、来源已落库
3. 伪造 `[[w9]]` → 正文无残留，且提示"模型引用了不存在的来源，已移除"
4. 相同 query 第二次 → provider 计数**不增加**（命中缓存）
5. 搜索超时 → 有"未能联网核实"提示，**无来源卡片、无假引用**
6. 提示 / 作答 / 解析三个接口 → provider 计数 **0**（判题隔离）
7. 关闭开关 → 立即回到零请求

浏览器实测：角标指向 `#source-w1`；来源卡片显示域名与发布日期；「打开原页」带 `rel="noopener noreferrer"`；点「打开材料」跳到 `/materials?chunk=…` 并显示"引用来源"面板与原文。

## 没做 / 已知限制

- **Phase 3 自动意图识别与工具循环**：按规格要求等评测数据（`tests/eval/web-cases.json` 24 条）齐了再做。当前自动模式不存在，不会误触发搜索。
- **引用语义校验**：只校验 id 是否存在，**不能证明来源真的支持那句结论**。UI 鼓励点开原页核对。
- **不存整页**：只存 ≤600 字摘要 + URL；正文仅在内存中用于注入。
- **抓取正文**只对摘要过短的前 2 条做，失败即退回"仅摘要"，不阻塞回答。
- **DNS rebinding** 是残余风险（本地单用户场景接受）；自建 provider 地址默认允许，关闭后连 provider 也走私网阻断。
- **真实 provider 未验证**：本机没有可用的 SearXNG/Tavily/Brave 凭据，真实联网调用**未验证**；端到端验证使用的是确定性替身。
