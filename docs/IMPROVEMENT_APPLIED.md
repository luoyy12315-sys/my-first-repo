# 改进建议落地记录

对应《Lumina 改进建议》（2026-10-22，14 项 / 3 批）的处理结果。
判断依据采纳报告自己的主张：**不加功能，先补闭环**——优先做能把「证据 → 诊断 → 行动」接通的部分。

## 已实现（批次一全部 + 批次二两项）

### A1 · 错因结构化 + 错题本

**做了什么**

- `attempts.error_type`：概念混淆 / 计算失误 / 审题遗漏 / 表述不全 / 知识缺口。
- 客观题由判题器**推断**（`inferErrorType`）：多选多选→概念混淆、仅漏选→审题遗漏；
  计算题偏差 ≤20%→计算失误、否则概念混淆；填空→表述不全；排序→审题遗漏。
- 知识点详情新增「错因分布」与「最近一次错答（选了哪个选项）」；练习反馈面板显示本次错因。
- 提示词新增【错因画像】：把「为什么错 + 当时写了什么」注入上下文，而不只是 p 值。
- **错因不进掌握度计算**，只影响怎么教（报告明确要求）。

**验证**：单元 4 例（各题型推断 + 答对不带错因）；真实链路连错两次后 `errorType=concept_confusion`，
档案显示「概念混淆 × N」。

### A2 · 结构化复习会话

**做了什么**

- `sessions.focus_concept_id / review_item_id`；`POST /api/sessions` 接受 `mode:"review"`。
- 复习页不再拼一句自然语言，而是传结构化参数；会话页进入空复习会话时自动开题。
- 提示词对 review 模式强约束：**先出题（同型 1 道 + 变式 1 道），拿到有效作答再讲**，不得用讲解代替检测。
- 答对后 `completeReviewForSession()` 把条目置为 done；未作答退出则条目保留。

**验证**：集成测试 2 例（绑定条目收尾 / 未绑定不动作）；
浏览器实测：复习页「练一练」→ 进入 `/s/...`、显示「复习 · 聚焦 X」、自动开出练习。

### A3 · 单条证据作废与重算

**做了什么**

- `evidence.voided / void_reason / voided_at`：**软作废**，审计与导出仍可见。
- `DELETE /api/evidence/[id]`；知识点详情逐条列证据，带「这条不算」二次确认。
- 复用 `recomputeConceptAggregates()` 重放剩余证据；作废动作写 `concept_events`。
- 作废最后一条 → 回到「尚未接触」、p 回到 0.1。

**验证**：集成测试（作废后重算、作废到零回到 untouched、记录仍保留且标记 voided）。

### C1 · 今日计划

- `/api/home` 返回 `todayPlan`：到期复习 > 最薄弱知识点 > 继续上次 > 空态。
- 首页顶部一张卡片：「今天 · 约 10 分钟」+ 一句理由 + 一键开始，走 A2 的结构化会话。
- 没有可安排内容时显示空态，不造假任务；当天已学过的薄弱点不再重复推荐。

### C2 · 题目反馈与「换一题」

- `exercise_feedback` 表 + `POST /api/exercises/[id]/feedback`：太简单 / 太难 / 有问题（可附说明）。
- 「有问题」→ 作废该题产生的全部证据并重算（复用 A3 路径）。
- 「换一题」→ `POST /api/exercises/[id]/retry`：同知识点、**换一种题型**，走与聊天工具相同的校验与落库路径；
  生成不合法直接 502，不伪造可用题。
- 反馈进入提示词，作为下一题难度与题型依据。

**验证**：端到端新增 4 项（换题成功 / 题型不同 / 以组件进入会话 / 不含答案）；
集成测试 1 例（反馈持久化）。
